## 🚀 How to Run

1. Make sure you have **Java JDK 8+** installed.
2. Navigate to the solution file:
   ```bash
   cd Java/0-500_Difficulty/
   ```
3. Compile and run:
   ```bash
   javac SolutionName.java
   java SolutionName
   ```

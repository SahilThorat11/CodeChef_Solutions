## 📌 About This Difficulty Range

- These are **entry-level** problems on CodeChef.
- They typically involve basic I/O, simple arithmetic, loops, and conditionals.
- Great for learning the structure of competitive programming problems.

## 🧩 Topics Covered

- ✅ Basic Input / Output
- ✅ Arithmetic & Math
- ✅ Conditionals (`if-else`, `switch`)
- ✅ Loops (`for`, `while`)
- ✅ Strings
- ✅ Arrays

## 🚀 How to Run a Solution

1. Navigate to this folder:
   ```bash
   cd Java/0-500_Difficulty/
   ```
2. Compile the Java file:
   ```bash
   javac ProblemCode.java
   ```
3. Run with input:
   ```bash
   java ProblemCode
   ```
